🔐 Password Strength Checker (Python)

A terminal-based Python tool that evaluates the strength of a password and provides actionable improvement suggestions.

If the password is weak, the program can generate a stronger version while preserving elements of the original structure.

This project is designed to be simple, educational, and easy to extend.

✨ Features

Evaluates password strength based on:

Minimum length (8+ characters)

Uppercase letters (A–Z)

Lowercase letters (a–z)

Numbers (0–9)

Symbols (special characters)

Classifies passwords as:

Weak ❌

Medium ⚠️

Strong ✅

Provides detailed improvement suggestions

Option to generate a stronger version of a weak password

Clean, beginner-friendly Python implementation

🛠 Technologies Used

Python 3

string module

random module

Basic input/output handling

🚀 How to Run

Clone the repository or download the file:

git clone <your-repo-url>

Navigate into the project folder:

cd password-strength-checker

Run the program:

python password_checker.py
